## 依赖

全部走 roothide，substrate 由 `@loader_path/.jbroot/usr/lib/libsubstrate.dylib` 载入，
`libroothide.dylib` 提供 `jbroot()` 做路径重定向。所以工程里所有路径都要经过
`jbroot()`，不能直接写 `/Library/...`。

## 五个组件各自的职责

### SystemBox（主 tweak，最大的一块）
15 个类、1 个 category（`UIImage+SystemBoxDockReflectionBlur`）、4 个协议、
521 条 hook。按 hook 目标分几块：

- **桌面图标**：`SBIconView` / `SBFolderIconImageView` / `SBApplicationIcon` /
  `SBHIconImageCache` —— 圆角、影子、隐藏、批量换图标。
- **Dock 玻璃**：`SBDockView`、`SBFloatingDockPlatterView`，配合
  `SBXLiveBackdropView` 自己画的镜面高光层（`CAGradientLayer` + mask）。
- **手势**：`SBHomePullUpControlCenterGestureTarget` 等 10 个 target 类，
  拦截下拉/上划/双击锁屏/长按锁屏。
- **相册**：`PHAssetCollection`、`PUDeletePhotosActionController`、
  `PXPhotoKitDeletePhotosActionController` —— 跳过删除确认。
- **状态栏 / 控制中心**：颜色化、百分比显示。

### SystemBoxClockGlass（UIKit 进程）
6 个类、148 个方法、55 条 hook。核心是 `MRUArtworkView`（锁屏/正在播放的
封面视图）上的玻璃透镜效果，用 `CABackdropLayer` + `CAFilter` 做折射。
另外通过 `notify_post` 向 backboardd 传参（`...lensrect.npartwork`）。

### SystemBoxClockGlassBackboardd（backboardd）
没有 ObjC 类，纯 C。它不调用 `MSHookMessageEx`，而是：

1. `dlsym` 解析 `MSHookFunction`、`CAInternAtomWithCString`、`add_filter`；
2. 扫描 QuartzCore 的 filter 注册表拿到 `gaussian` vtable；
3. 替换 vtable 里的 render / edge-info 槽位，插入自己的 Metal 渲染 pass；
4. 有防崩溃保护：`/var/mobile/Library/Accessibility/systembox-clockglass-guard.bin`
   记录启动次数，短时间内反复启动会写 `...-safemode.log` 并卸载 hook。

### SystemBoxLiquidGlassDockBackboardd（backboardd）
同上机制，但更小（90 KB），只做 Dock 的液态玻璃材质替换，配
`DockGlass.metallib`。

### SystemBoxPrefs（设置面板）
14 个类、95 个方法，标准 `PSListController` 结构，9 个 plist 驱动：
Root / General / Desktop / Folder / Hide / Disable / Photos / Clock / DateTime，
另有 `PSLinkCell` 入口和 Sileo 源跳转、开发者资料单元格。

## 配置键

139 个开关，全部在 `Analysis/prefs-map.tsv` 里对应到原二进制里的全局地址，
`src/Common/Prefs.h` 是一份可直接用的映射表。
