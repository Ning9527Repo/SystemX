# 05 · 编译

## 需要

- Theos（`THEOS` 环境变量指向它）
- iOS SDK 16.5 或 15.x
- 两个架构都要：`ARCHS = arm64 arm64e`

## 编译

```bash
export THEOS=/opt/theos
make clean
make package
```

产物：`packages/com.wkk.systembox_1.5-8-rebuilt_iphoneos-arm64e.deb`

## 装机

```bash
dpkg -i packages/*.deb
# 或者用 Sileo / Filza 直接安装，装完 respring
```

## 工程结构

```
Makefile                5 个 tweak + 1 个 bundle
control                 包信息（与原包一致）
layout/                 原包全部资源 + 4 个注入 plist
src/Common/             Prefs.h（139 个开关映射）、DecompiledRuntime.h
src/SystemBox/          15 个类 + 1 个 category + Hooks.xmi（521 条）
src/SystemBoxClockGlass/ 6 个类 + Hooks.xmi（55 条）
src/SystemBox*Backboardd/ 完整 C 源码
src/SystemBoxPrefs/     14 个设置面板类
Analysis/               反编译全文、hook 表、元数据
docs/                   本目录
tools/                  解析器与生成器（可复现整个过程）
```

## 第一步建议先做什么

先把 `src/SystemBox/Hooks.xmi` 里 `UnknownClass` 的地方补上类名
（15 条没解析出来的注册点，`Analysis/hooks.md` 里标了 `?`），
然后逐个组件把 `.m` 里的变量名整理掉。
